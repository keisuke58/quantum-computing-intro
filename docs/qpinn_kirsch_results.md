# QPINN ベンチ #2: 円孔付き板の応力集中（Kirsch 解）

生成元: `13_qpinn_kirsch.py`

研究計画の #3（星形グレイン）の差し替え。応力集中という論点は維持したまま、解析解のある
問題にすることで FEM 参照解の工数と非圧縮性（ν→0.5）の体積ロッキングを回避している。

## 問題設定

遠方一軸引張 S を受ける円孔付き無限板の、円孔まわりの円環領域 a ≤ r ≤ R（a=1, R=4）。

- 支配方程式: 平面応力の平衡方程式 ∂σ_xx/∂x + ∂σ_xy/∂y = 0, ∂σ_xy/∂x + ∂σ_yy/∂y = 0
- 内側 r=a: traction-free（σ_rr = σ_rθ = 0）← 応力集中が起きる面
- 外側 r=R: 変位の Dirichlet 条件（Kirsch 解を与える）
- E=1, ν=0.3, S=1

### #1（Lamé）との違い

| | #1 厚肉円筒 | #2 円孔付き板（これ） |
|---|---|---|
| 次元 | 1D（軸対称） | 2D |
| 出力 | スカラー u(r) | **ベクトル場 (u, v)** |
| 解の性質 | 滑らか | **応力集中** |
| 検証量 | 変位・応力の L2 | L2 + **応力集中係数 K_t** |

### 解析解の検証

Muskhelishvili の複素ポテンシャル φ(z) = S/4(z + 2a²/z), ψ(z) = -S/2(z + a²/z - a⁴/z³) から
変位と応力を出し、3つの独立な方法で検証した（`--verify-only` で再現可能）:

| 検証 | 結果 |
|---|---|
| 複素ポテンシャル由来の応力 vs 教科書の極座標 Kirsch 公式 | max\|diff\| = 8.9e-16 |
| 孔縁 r=a の traction-free（σ_rr, σ_rθ = 0） | max\|diff\| = 7.5e-16 |
| 応力集中係数 K_t | **3.000000**（理論値 3） |
| 変位→ひずみ→Hooke で応力に戻るか（有限差分） | max\|diff\| = 4.8e-10 |

## 結果 1: PDE 学習（physics only、データ損失なし）

collocation 512 点、Adam + cosine annealing。古典 20000 step / QPINN 1500 step。

| モデル | params | rel L2(u) | rel L2(σ) | K_t | 秒 | 表現力の上限 |
|---|---|---|---|---|---|---|
| 古典 PINN（MLP 32×3） | 2274 | **7.27e-02** | 1.12e-01 | **2.957** | 283 | 1.51e-02 |
| Fourier feature PINN | 546 | 2.94e-01 | 4.68e-01 | 1.921 | 193 | 1.20e-02 |
| 素の QPINN（4 qubit） | 52 | 7.20e-01 | 1.11e+00 | 0.734 | 1437 | 3.28e-01 |

「表現力の上限」= 解析解の変位を直接フィットした時の rel L2（PDE 損失を使わない）。

**K_t の真値は 3.000。** L2 誤差が小さくても K_t を外すことがあるので併記している。
実際 Fourier feature PINN は rel L2(u)=0.29 に対し K_t=1.92 と、応力集中を 36% 過小評価している。

## 結果 2: #1 と逆の結論 — 2D では表現力が律速

| | #1 Lamé（1D・滑らか） | #2 Kirsch（2D・応力集中） |
|---|---|---|
| QPINN の表現力 | 7.21e-04 | **3.28e-01** |
| QPINN の PDE 学習 | 5.23e-02 | 7.20e-01 |
| 比（PDE / 表現力） | 72× | **2.2×** |
| **律速要因** | **最適化** | **表現力** |

#1 では「表現できるのに PDE 損失で学習できない」が問題だった（比 72×）。
#2 では比が 2.2× まで落ちる。つまり **PDE 学習は表現力の上限までほぼ到達しており、
その上限自体が低い**。2D のベクトル場＋応力集中は、素の角度エンコード回路の関数クラスに
そもそも入っていない。

### qubit を増やしても埋まらない

表現力だけを測るスイープ（PDE 損失なし、教師ありフィット 2000 step）:

| 構成 | params | 表現力 rel L2(u) | K_t |
|---|---|---|---|
| 4 qubit / 3 層 / 再UP 2 | 52 | 3.28e-01 | 4.736 |
| 6 qubit / 3 層 / 再UP 2 | 76 | 2.57e-01 | 3.777 |
| 8 qubit / 3 層 / 再UP 2 | 100 | 2.70e-01 | 2.196 |
| 4 qubit / 3 層 / 再UP 3 | 76 | 2.65e-01 | 5.161 |
| 6 qubit / 4 層 / 再UP 3 | 148 | 2.16e-01 | 4.844 |
| （参考）古典 MLP 32×3 | 2274 | **1.51e-02** | 2.658 |

8 qubit まで増やしても 2.2e-1 前後で頭打ちで、古典 MLP との差は 1 桁以上残る。
**回路を大きくしても埋まらない。**

※ この表の実行時間は他プロセスとの CPU 競合を含むため信頼できない（6 qubit が 8 qubit より
遅いのはそのため）。精度の値は影響を受けない。

## 結果 3: 古典層のサンドイッチが頭打ちを破る

OIST の Rakala 実装（[github.com/GeetRakala/QPINN](https://github.com/GeetRakala/QPINN)、
2D Navier-Stokes 円柱後流）を参考に、古典層で挟むハイブリッド構成を試した。
向こうは素の量子（79 params, loss 1.03e-1）に古典層を足して 311 params で 2.89e-2 と
3.5 倍改善している。

構成: `(x, y) → Dense(8) → tanh → Dense(n_q) → 量子回路 → Dense(8) → tanh → Dense(2)`

表現力（教師ありフィット 2000 step）:

| モデル | params | 表現力 rel L2(u) | K_t |
|---|---|---|---|
| 素の QPINN 4 qubit | 52 | 3.28e-01 | 4.736 |
| **ハイブリッド 4 qubit** | 166 | **2.59e-02** | 2.615 |
| **ハイブリッド 6 qubit** | 224 | **2.04e-02** | 2.596 |
| **古典層のみ（量子回路なし）** | 67 | **3.06e-01** | 2.118 |
| （参考）古典 MLP 32×3 | 2274 | 1.51e-02 | 2.658 |

**13 倍改善した（3.28e-01 → 2.59e-02）。** ハイブリッド 4 qubit は 166 パラメータで、
2274 パラメータの古典 MLP（1.51e-02）に 1.7 倍差まで迫る。

> **⚠ 2026-10-02 追記: この節の結論は保留。** ここで使った対照（`QPINNHybrid(n_qubits=0)`）は
> 中間の幅が 1 に潰れていて、量子回路と同じ幅の情報を通せない不公平な対照だった。
> 公平な対照（幅 4 の恒等写像）を使った 2D 熱弾性の実験では、**回路なしの方が回路ありより良かった**
> （[qpinn_controls_results.md](qpinn_controls_results.md)）。Kirsch でも同じ対照で取り直すまで、
> 「量子回路は実際に寄与している」とは言えない。

### 最も重要な対照実験

「ハイブリッドが良いのは中身がただの古典 MLP だからでは？」という査読者の当然の疑いに対し、
**量子回路を取り除いた古典層のみ（67 params）は 3.06e-01 で、素の QPINN と変わらない**。
つまり古典層だけでも、量子回路だけでも駄目で、**組み合わせて初めて 2.59e-02 に届く**。
量子回路は実際に寄与している。

この対照（`QPINNHybrid(n_qubits=0)`）は論文に必ず入れること。

## 結果 4: 表現力を直すと、今度は最適化が律速になる

ハイブリッド構成で PDE 学習（2000 step）を回した結果:

| モデル | params | 表現力 | PDE 学習 | 比 | K_t | 律速要因 |
|---|---|---|---|---|---|---|
| 素の QPINN 4 qubit | 52 | 3.28e-01 | 7.20e-01 | 2.2× | 0.734 | **表現力** |
| ハイブリッド 4 qubit | 166 | 2.59e-02 | 5.30e-01 | **20×** | 0.246 | **最適化** |
| 古典層のみ（回路なし） | 67 | 3.06e-01 | 6.14e-01 | 2.0× | 0.084 | 表現力 |
| 古典 PINN（MLP 32×3） | 2274 | 1.51e-02 | 7.27e-02 | 4.8× | 2.957 | — |

ハイブリッドは表現力を 13 倍改善したのに、**PDE 学習の結果は 7.20e-01 → 5.30e-01 と
1.4 倍しか良くならない**。比が 2.2× から 20× に跳ね上がっており、**表現力の壁を破った途端に
その下にあった最適化の壁が露出した**。

つまり 2D・応力集中では**2つの壁が直列に存在する**:

1. 素の回路では表現力が足りない（qubit を増やしても埋まらない）
2. 古典層で表現力を確保すると、今度は PDE 損失での最適化が #1 と同じように律速になる

片方だけ直しても PDE 学習の結果はほとんど動かない。これが「QPINN を固体力学に適用する」
ことの実際の難しさで、論文の主張としてはこの直列構造そのものを出すのが最も誠実。

なお K_t はどの QPINN 系も 1 未満（真値 3.000）で、応力集中を**ほぼ全く捉えられていない**。
L2 誤差が 0.5 程度では K_t の議論に入る以前の段階。

## 結果 5: L-BFGS は古典 PINN を救うが QPINN は救わない

Adam の後に L-BFGS 仕上げを入れた（Rakala 実装が Adam → L-BFGS-B を使っているのに倣った）。
結果 4 で「最適化が律速」と分かったので、ここが効くはずという予想だった。

| モデル | params | Adam のみ | + L-BFGS | 改善 | 時間 |
|---|---|---|---|---|---|
| 古典 PINN（MLP 32×3） | 2274 | 2.03e-01 | **6.50e-02** | **3.1×** | 48s |
| Fourier feature PINN | 546 | 3.43e-01 | 2.97e-01 | 1.15× | 30s |
| ハイブリッド QPINN 4q | 166 | 5.50e-01 | 4.88e-01 | 1.13× | 1203s |
| 素の QPINN 4q | 52 | 7.48e-01 | 6.96e-01 | 1.07× | 1083s |
| 古典層のみ（回路なし） | 67 | 4.75e-01 | **6.08e-01** | **0.78×（悪化）** | 12s |

### 古典 PINN は L-BFGS で別物になる

Adam 2000 step + L-BFGS 50 回で **6.50e-02**。これは **Adam 20000 step 単独（7.27e-02）より良く、
しかも 48 秒 vs 283 秒で 6 倍速い**。PINN に L-BFGS 仕上げを入れないのは単に損。
K_t も 2.506 → 3.223 と、真値 3.000 をまたぐところまで来る。

### QPINN は 1.1 倍しか動かない

予想は外れた。ハイブリッド QPINN は最適化律速（比 20×）のはずなのに、L-BFGS を入れても
5.50e-01 → 4.88e-01 と 13% しか改善しない。しかも計算時間は 1203 秒（古典の 25 倍）。

**つまり QPINN の最適化の壁は、2次法で直せる種類のもの（悪条件・Adam の収束の遅さ）ではない。**
古典 PINN の壁は悪条件だったので L-BFGS が効いた。QPINN の壁は損失地形そのものの悪さで、
barren plateau 系の現象と整合する。これは「最適化を頑張れば QPINN も届く」という楽観を
定量的に否定する材料になる。

### loss と真の誤差が逆方向に動く

対照モデル（古典層のみ、量子回路なし）では、L-BFGS が **loss を 7.64 → 5.24 に 31% 下げた
のに、rel L2(u) は 0.475 → 0.608 に 28% 悪化した**。

PDE 損失には真の解とは別の方向に自明に近い谷があり、損失を下げることと解に近づくことが
一致しない領域がある。**ベンチマークの評価を loss で行ってはいけない**ことの直接的な証拠で、
PINN 一般に効く注意点。論文では必ず参照解との誤差で評価すること。

## 読み取れること

1. **問題の難しさで律速要因が入れ替わり、しかも直列に重なる。** 1D・滑らか（#1）では
   最適化だけが壁だった。2D・応力集中（#2）では、まず表現力の壁があり、それを古典層で
   破ると下から最適化の壁が出てくる。「QPINN の限界は barren plateau」という一言で
   片付けられない。これは定量的な主張として出せる。
2. **素の角度エンコード回路は 2D ベクトル場に届かない。** qubit を増やしても埋まらず、
   古典層との組み合わせが必要。パラメータ効率を主張するなら素の構成では無理。
3. **K_t は L2 誤差と独立に悪化する。** Fourier feature PINN は L2 0.29 に対し K_t 1.92
   （36% 過小評価）。応力集中を扱う以上、L2 だけの評価は不十分。
4. **ハイブリッドは「量子が効いているか」の対照が必須。** 古典層のみのアブレーションを
   入れないと主張が成立しない。
5. **L-BFGS 仕上げは古典 PINN には必須、QPINN には効かない。** 古典は 3.1 倍改善して
   Adam 20000 step より良く・6 倍速くなる。QPINN は 1.1 倍。QPINN の最適化の壁は
   2 次法で直せる悪条件ではない。
6. **loss で評価してはいけない。** 対照モデルで loss が 31% 下がりながら真の誤差が 28%
   悪化する例が出た。評価は必ず参照解との誤差で行う。
