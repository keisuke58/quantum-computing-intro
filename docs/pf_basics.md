# Phase-field 法の基礎（2026-11-03 メモ）

## 1. 何をしたいか
2 種類の物質が混ざった状態から，それぞれの「領域」（相）に分かれていく様子を計算したい．
対象は合金の組織，凝固，き裂など，材料の中の境界（界面）の形が時間で変わる現象．

## 2. 秩序変数 u
- 場所ごとに「どちらの相か」を表す変数 u(x, t) を置く．u = +1 なら相 A，u = −1 なら相 B
- 界面では u が −1 から +1 へなめらかに変わる
- 界面を線として追いかけずに，u の場を解くだけで界面の動きがわかるのが利点

## 3. 自由エネルギー
系は自由エネルギー E が下がる方向に変化する．

E[u] = ∫ ( F(u) + (κ/2) |∇u|² ) dx

- **F(u) = (1/4)(u² − 1)²（二重井戸）**：u = ±1 で最小．「どちらかの相になりたい」性質
- **(κ/2)|∇u|²（勾配の項）**：u が急に変わると損をする．界面を厚くしたがる
- 2 つの項のつり合いで界面の幅（√κ 程度）が決まる

図：`figs/pf_explain.png`（(a) 二重井戸，(c) 界面の形）

## 4. Allen–Cahn と Cahn–Hilliard
どちらも「E が下がるように u を動かす」式．動かし方が違う．

**Allen–Cahn（AC）**：u_t = −δE/δu = κ u_xx − (u³ − u)
- 各点で u がその場で増えたり減ったりできる．相の量は保存されない
- 例：結晶の秩序化，結晶粒の成長
- 空間の微分は 2 階

**Cahn–Hilliard（CH）**：u_t = (μ)_xx，μ = δE/δu = (u³ − u) − κ u_xx
- u は場所の間を移動するだけなので，全体の量 ∫u dx が保存される
- 例：合金の相分離（スピノーダル分解）
- 空間の微分は 4 階．μ（化学ポテンシャル）を別の未知数にすると 2 階 × 2 に分けて解ける（混合形）

## 5. なぜ難しいか
- 界面がとても薄く，そこだけ急に変わるので，細かく表現できる手法が必要（今回の AC で幅 0.04 程度）
- 時間方向も速い部分と遅い部分が混ざる（硬い方程式）
- 普通の PINN は AC で誤差 0.99 とほぼ解けない（Wight & Zhao 2021）

## 6. 今回の解き方との対応
- u を固定の特徴量（量子リザバーなど）の足し合わせで表す
- 時間は一歩ずつ進め，各ステップで u³ を Newton 法で線形化し，最小二乗で係数を求める（勾配法の学習はなし）
- CH は μ も同じ特徴量で表して，u と μ を一緒に解く
