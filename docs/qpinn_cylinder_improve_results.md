# 円柱後流 QPINN（Rakala improved）の改良実験

生成元: `18_qpinn_cylinder_improve.py`，図: `23_fig_cylinder_improve.py`（`figs/cyl_errors.*`，`figs/cyl_vorticity.*`）
学習条件は原著と同じ（学習点 5,000，L-BFGS-B 2,000 反復，float32）．全 200 時刻の相対 L2 誤差の平均．

| モデル | params | u | v | p | 時間/シード |
|---|---|---|---|---|---|
| V0 量子 improved（再実行） | 311 | 0.099 / 0.108 | 0.286 / 0.352 | 0.392 / 0.416 | 約 2,300 s |
| V1 回転角 ×π | 311 | 0.114 / 0.117 | 0.360 / 0.365 | 0.481 / 0.526 | 約 2,350 s |
| V3 測定量 12 個（V2 + 再アップロード） | 439 | 0.112 | 0.346 | 0.401 | 4,101 s |
| C-identity（量子回路を除去） | 263 | 0.106 / 0.106 | 0.350 / 0.334 | 0.457 / 0.435 | 約 550 s |
| **C-mlp311（同規模の古典 MLP）** | 311 | **0.062 / 0.063** | **0.203 / 0.184** | **0.197 / 0.222** | 約 300 s |

（seed 0 / seed 1．V2 単独と V3 の seed 1 は時間制限で未完了）

## 読み取れること

1. **量子回路の改良（角度・再アップロード・測定量）はいずれも効かない．** V1 はむしろ悪化，V3 もほぼ同じ．
2. **量子回路を取り除いても精度はほぼ同じ**（u 0.103 → 0.106）．計算時間は 1/4．
3. **同じ 311 パラメータの古典 MLP が全変数で最良**（u 0.06，p 0.21）で，量子 improved の約 1/2 の誤差，時間は 1/8．
4. 渦度の比較でも，古典 MLP は渦の強さを最もよく再現し，量子 improved と回路なしはほぼ同じ平滑化された分布になる．

→ 固体力学（`qpinn_controls_results.md`）と同じ結論が，Rakala の流体問題でも再現された．
