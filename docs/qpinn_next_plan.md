聴衆は量子計算寄り．これまでの結果（同規模の古典モデルと公平に比較すると QPINN の優位はない）を踏まえ，
「なぜ駄目か」を足がかりに，前向きな結果を狙う．

## これまでに分かっていること

| 問題 | 律速要因 | 根拠 |
|---|---|---|
| Lamé（1D・滑らか） | 最適化 | 表現力 7e-4 に対し PDE 学習 5e-2（72 倍） |

## アイデアの優先順位

### 1. 物理を考慮したエンコーディング（最初に試す）

量子回路の出力は入力角度のフーリエ級数（Schuld et al. 2021）．一方 Kirsch 解は極座標で

    u_r = r [ α₀ + α₁ρ² + (β₀ + β₁ρ² + β₂ρ⁴) cos 2θ ]，u_θ = r (γ₀ + γ₁ρ² + γ₂ρ⁴) sin 2θ，ρ = a/r

の形をしている．デカルト座標 (x, y) をそのまま角度に入れると，この形はフーリエ級数で表しにくい．そこで

- θ をそのまま回転角に入れる → cos 2θ, sin 2θ は低次のフーリエ成分で厳密に表せる
- ρ = a/r を Chebyshev エンコーディング（角度 = arccos ξ）で入れる → 出力は ξ の多項式
- 出力に r を掛け，極座標成分 (u_r, u_θ) をデカルト成分に変換する

とすれば，解析解は回路の関数クラスにほぼ含まれる．回路そのものは変えず，座標の入れ方だけを変える．

公平な対照として，**同じ座標・同じ前処理を与えた同規模の古典 MLP** を必ず入れる
（「良くなったのは座標変換のおかげで，量子回路のおかげではない」という指摘に答えるため）．

実装: `19_qpinn_physenc_kirsch.py`

### 2. QELM / QERC-PINN（最小二乗法 1 回で解く）

量子回路を学習せず固定し，測定値を特徴量として最後の線形層だけを解く．線形弾性では
PDE 残差・境界条件が出力重みについて線形なので，学習は最小二乗法 1 回で終わる．最適化の壁がなくなる．

- 既存研究: Quantum Random Feature Method（arXiv:2510.07945）．差別化は
  ① 固体力学・応力集中 K_t での評価，② 同じ特徴量数の古典ランダム特徴量（PIELM）との公平比較，
  ③ QERC 型のハミルトニアン時間発展をリザバーに使う
- 1 と組み合わせる（物理エンコーディング＋QELM）と，表現力と最適化の両方の壁に同時に対処できる

### 3. エネルギー形（DEM）による実機向け QPINN

DEM は 1 階微分のみ．parameter-shift 則での回路実行回数を残差形と比べ，小さな問題を
ノイズ付きシミュレータ／実機で解く．

### 4. 逆問題（DIC データからの材料定数推定）

少パラメータ・ノイズ耐性が活きるが，古典との差は出にくい見込み．

| N qubit | 特徴量 2^N | QERC | 古典 RF（同数） | 古典 RF（N 個） |
|---|---|---|---|---|
| 4 | 16 | 2.5e-01 / 2.3e-01 | 1.9e-01 / 2.7e-01 | 6.8e-01 / 7.3e-01 |
| 6 | 64 | 1.4e-02 / 1.4e-02 | 1.4e-02 / 4.2e-03 | 4.0e-01 / 6.9e-01 |
| 8 | 256 | **2.1e-03** / 2.1e-03 | 7.6e-05 / 6.8e-05 | 5.9e-01 / 5.0e-01 |

- 変分 QPINN（最良でハイブリッド 2.6e-02，素の回路 2e-1 で頭打ち）より 1〜2 桁良い．学習は数秒．
- 同じ qubit 数・ニューロン数 N で比べると QERC が圧倒的（指数個の特徴量）．
- ただし同じ特徴量数（＝同じ読み出し重み数）の古典ランダム特徴量には 1 桁以上負ける．
  主張の置き方は「N 個の物理資源から 2^N 個の有用な特徴量」であり，「特徴量 1 個あたりの質」では古典が上．

### 重要な発見: リザバーの中身は表現できる関数を変えない

イジング時間 t（0.2〜5）・結合のシードを変えても，PDE の結果は小数 3 桁まで同じだった．
特徴量行列のランクを調べると（3000 点）:

| N | 特徴量 2^N | ランク | 別のリザバーと連結したランク |
|---|---|---|---|
| 6 | 64 | 64 | 80 |
| 8 | 256 | **152** | **152** |

理由: p_k(x) = Tr[U†|k⟩⟨k|U ρ(x)] は ρ(x) について線形なので，特徴量の張る空間は常に
「ρ(x) の行列要素が張る関数空間」に含まれる．一般的な U ならその全体を張るので，
**リザバー（時間発展・結合）を何に変えても線形読み出しで表せる関数は同じで，エンコーディングだけで決まる**．
N=8 では 256 個の特徴量のうち独立なのは 152 個で，「2^N 個の特徴量」は実効的には成り立っていない
（全 qubit に同じ入力を入れているため，ρ(x) の要素は低次の三角多項式に限られる）．

→ 量子リザバーで PDE を解く場合の設計自由度はエンコーディングにしかない．発表の主張として使える．

### Ikeda et al. (2026) 型エンコーダでの QERC-PINN（`25_qerc_ikeda_pde.py`）

Ikeda, Sakurai, Nemoto, Muramatsu (arXiv:2601.02150) と同じく，qubit ごとに別の入力
（θ_l, φ_l）を入れる．PCA の代わりに (arccos ξ, cos θ, sin θ) のランダムなアフィン結合で 2N 個の角度を作る．
PDE のみ・最小二乗 1 回，コロケーション 8000 点．rel L2(u)（seed 0 / seed 1），括弧内はランク．

| リザバー | N=8 | N=10 | K_t（N=10） |
|---|---|---|---|
| なし（恒等） | 4.1e-01 / 1.6e-01（243） | 1.3e-01 / 7.1e-03（537/480） | 2.28 / 2.98 |
| Clifford のみ | 3.2e-01 / 3.1e-01（256） | 1.2e-01 / 3.1e-02（669/709） | 2.60 / 2.92 |
| **Clifford + T** | 8.2e-02 / 4.0e-02（256） | **1.3e-03 / 5.4e-04**（889/876） | **3.02 / 3.00** |
| イジング | 6.1e-02 / 2.0e-02（256） | 7.0e-03 / 6.3e-04（907/885） | 3.07 / 3.01 |
| **Haar** | 6.7e-02 / 1.2e-02（256） | **1.2e-03 / 3.2e-04**（915/894） | **2.99 / 3.00** |
| 古典 RF（同数） | 9.0e-03 / 2.7e-03（227/229） | 7.2e-04 / 6.1e-04（598/597） | 3.00 / 3.01 |

（参考: 22 の「全 qubit に同じ入力」は N=8 で 2.4e-01，リザバーによらず一定）

読み取れること:
1. **仮説を確認: エンコーディングの空間が大きいとき，リザバーが効く．** なし・Clifford のみでは 1e-1 前後，
   Clifford+T・イジング・Haar では N=10 で 1e-3〜3e-4 と 2 桁違う．Clifford のみでは不十分という点は
   Ikeda らの分類の結果（Fig. 4(b)）と一致．
2. **N=10 で古典ランダム特徴量と同等**（seed 1 では Haar 3.2e-4 vs 古典 6.1e-4）．K_t も 3.00．
   22 の設計（2.4e-1）から 2〜3 桁改善．
3. 独立な特徴量の数は量子の方が多い（N=10 で 876〜915 vs 古典 RF 597〜598）．tanh 特徴量は飽和で縮退しやすい．

注意: 2 シードのみ．古典 RF の重みスケール（1.5）は調整していない．公平のため古典側もスケールを振る必要がある．

## 今後の対象（2026-10-02 メモ）

Kirsch のような滑らかな解では古典の低周波特徴量が強い．量子特徴量（三角多項式）の構造が活きる対象として，
**周期微細構造の固体力学**に移る．同じコード（QERC-PINN + 領域分割 + 界面の連続条件）で以下を順に扱う．

1. **TSV（シリコン貫通電極）1 本の熱応力**：Cu/Si 同心円，平面ひずみ，解析解あり（Lamé 型）．精度の検証用．
2. **TSV 周期配列**：単位セル + 周期境界条件．ピッチを詰めたときの応力場の重なり（KOZ の見積もり）．参照は FEM．
3. **CFRP 繊維単位セルの均質化**：まず面外せん断（スカラー ∇·(G∇w)=0）で等価 G₁₂ を Halpin-Tsai・FEM と比較．
   次に面内（E₂, ν₂₃）．先輩（Ikeda et al. 2026）の SCFT 微細構造（ヘキサゴナル等）にもそのまま適用できる．
4. **積層板・フォノニック結晶の弾性波**（周波数領域，ベクトル Helmholtz = Navier + ρω²u）：高周波の比較．
   FS-PIELM（arXiv:2607.01694）と直接比較する場面．

難点: 材料界面で係数が不連続 → 相ごとに別の特徴量を使い，界面での変位・表面力の連続条件を最小二乗に加える．

発表（3 か月後，台湾）の構成案: 変分 QPINN の否定的結果 → QERC-PINN（最適化の壁なし）→ リザバーの役割の理論
（エンコード空間の次元 > 2^N のときだけ効く）→ ショットノイズ → 公平な比較（cos 型古典特徴量を含む）→ 周期微細構造への応用．
