## アイデアの優先順位

### 1. 物理を考慮したエンコーディング（最初に試す）

量子回路の出力は入力角度のフーリエ級数（Schuld et al. 2021）．一方 Kirsch 解は極座標で

    u_r = r [ α₀ + α₁ρ² + (β₀ + β₁ρ² + β₂ρ⁴) cos 2θ ]，u_θ = r (γ₀ + γ₁ρ² + γ₂ρ⁴) sin 2θ，ρ = a/r

の形をしている．デカルト座標 (x, y) をそのまま角度に入れると，この形はフーリエ級数で表しにくい．そこで

- θ をそのまま回転角に入れる → cos 2θ, sin 2θ は低次のフーリエ成分で厳密に表せる
- ρ = a/r を Chebyshev エンコーディング（角度 = arccos ξ）で入れる → 出力は ξ の多項式
- 出力に r を掛け，極座標成分 (u_r, u_θ) をデカルト成分に変換する

とすれば，解析解は回路の関数クラスにほぼ含まれる．回路そのものは変えず，座標の入れ方だけを変える．

公平な対照として，**同じ座標・同じ前処理を与えた同規模の古典 MLP** を必ず入れる
（「良くなったのは座標変換のおかげで，量子回路のおかげではない」という指摘に答えるため）．

実装: `19_qpinn_physenc_kirsch.py`

### 2. QELM / QERC-PINN（最小二乗法 1 回で解く）

量子回路を学習せず固定し，測定値を特徴量として最後の線形層だけを解く．線形弾性では
PDE 残差・境界条件が出力重みについて線形なので，学習は最小二乗法 1 回で終わる．最適化の壁がなくなる．

- 既存研究: Quantum Random Feature Method（arXiv:2510.07945）．差別化は
  ① 固体力学・応力集中 K_t での評価，② 同じ特徴量数の古典ランダム特徴量（PIELM）との公平比較，
  ③ QERC 型のハミルトニアン時間発展をリザバーに使う
- 1 と組み合わせる（物理エンコーディング＋QELM）と，表現力と最適化の両方の壁に同時に対処できる

### 3. エネルギー形（DEM）による実機向け QPINN

DEM は 1 階微分のみ．parameter-shift 則での回路実行回数を残差形と比べ，小さな問題を
ノイズ付きシミュレータ／実機で解く．

### 4. 逆問題（DIC データからの材料定数推定）

少パラメータ・ノイズ耐性が活きるが，古典との差は出にくい見込み．
